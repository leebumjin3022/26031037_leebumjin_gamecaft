# 12프레임 리소스

- 청팀/홍팀 12개 동작씩 및 충격파: 총 25개 모션, 개별 PNG 300장.
- 모든 개별 프레임은 512×512 RGBA PNG이며 frame_01.png부터 frame_12.png 순서입니다.
- 각 동작의 sheet.png는 4열×3행입니다.
- 기존 그림을 참고해 내장 이미지 생성 도구로 중간 자세를 포함한 12프레임 모션을 새로 그렸습니다. 원본과 세부 형태가 다를 수 있습니다.
- 캐릭터 프레임은 몸 전체를 보존해 분리하고 모션별 동일 배율 및 하단 기준으로 정렬했습니다. 점프의 화면상 높이는 게임의 캐릭터 좌표로 이동시켜 주세요.
- 재생 권장 시작값: 대기 6~8fps, 이동/뒤로 걷기 18~24fps, 공격은 공격 지속시간에 12장을 배분, 충격파 30~36fps 단발, 패배는 마지막 프레임 유지.
- animation12_preview.html에서 모션 전체를 재생하며 속도를 조절할 수 있습니다.

## 게임 연동 참고

현재 src/dicefight/Resources.cs의 ResourceMap.Frames는 6입니다. 새 12장을 전부 사용하려면 12로 바꾸어야 합니다. CrouchFrame은 새 시트의 가장 낮은 자세인 인덱스 5 또는 6을 사용하세요. 현재 IdleFrame은 왕복 재생 로직이므로 순환형 대기 모션을 사용할 경우 순방향 반복으로 조절할 수 있습니다. 기존과 같은 시간에 두 배의 프레임을 표시하려면 재생 속도도 함께 조절해야 합니다.

이번 작업은 리소스 파일 제작/저장 범위이며 게임 소스 및 실행 파일은 변경하지 않았습니다. 게임 내부에서 최종 재생/공격 판정 타이밍 검증은 별도로 필요합니다.
