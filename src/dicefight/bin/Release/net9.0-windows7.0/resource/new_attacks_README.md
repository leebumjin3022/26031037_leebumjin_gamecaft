# 신규 공격 12프레임 리소스

기존 청팀·홍팀 캐릭터를 참고하여 내장 이미지 생성 도구로 만든 추가 이미지입니다. 각 동작은 투명 PNG 12장과 4열 × 3행 묶음 이미지로 구성합니다.

## 구성

두 팀의 폴더에 각각 다음 동작을 추가합니다.

| 폴더 | 동작 | 권장 연결 |
| --- | --- | --- |
| 13_heavy_charge | 강공격 차징 | 대기 → 12프레임 차징 → 마지막 자세 유지 |
| 14_heavy_attack | 강공격 발동과 회수 | 차징 완료 후 키를 놓으면 재생 → 대기 |
| 15_jump_attack | 대각선 아래 날아차기 | 기존 점프의 공중 구간 → 발차기 → 착지 |
| 16_special_cast | 장풍 발사 | 대기 → 두 손 앞으로 발사 → 대기 |

효과 폴더에는 `effects/heavy_impact`, `effects/projectile_blue`, `effects/projectile_red`를 추가합니다. 장풍은 이동 중 반복 재생용이며 강공격 충격파는 한 번 재생합니다.

## 이미지 규격

- 개별 파일: `frame_01.png` ~ `frame_12.png`, 512 × 512, 투명 배경.
- 묶음: `sheet.png`, 2048 × 1536, 왼쪽에서 오른쪽으로 4장씩 3행.
- 오른쪽을 바라보는 원본입니다. 왼쪽 방향은 게임에서 좌우 반전합니다.
- 캐릭터의 바닥 기준은 이미지 아래에서 32px 위입니다. 공중 이동은 게임 좌표로 처리합니다.
- 미리보기: `new_attacks_preview.html`. 속도 조절과 일시정지를 지원합니다.

## 재생 참고

- 차징 12프레임을 24fps로 재생하면 0.5초입니다. 이후 마지막 프레임을 유지하고, 키를 놓았을 때만 발동 동작으로 바꿉니다. 차징을 반복 재생하거나 자동으로 공격하지 않습니다.
- 강공격 발동 5~7프레임 부근을 타격 구간으로, 특수공격 7프레임 부근을 장풍 생성 시점으로 사용할 수 있습니다. 이는 이미지에 맞춘 권장값이며 실제 판정은 게임에서 조정합니다.
- 점프공격은 이미 공중에 있을 때 시작합니다. 착지 프레임은 실제 지면 도착 시점에 맞춰 사용합니다.
- 데미지, 사거리, 판정, 쿨타임과 키 입력은 이미지에 포함되지 않습니다. 게임 소스 코드는 수정하지 않았습니다.
- 생성 이미지 특성상 자세 사이의 형태 변화가 있으므로 최종 재생 속도와 위치는 게임 안에서 확인해주세요.

제작에 사용한 프롬프트는 `new_attacks_prompts.json`에 보관합니다.
