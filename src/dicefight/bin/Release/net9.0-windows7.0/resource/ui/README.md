# UI 리소스

내장 이미지 생성 도구로 기존 게임의 금빛 글자와 목재/금속 장식에 맞춰 제작했습니다. 게임 소스에는 아직 연결하지 않았습니다.

- numbers/0.png ~ 9.png: 각 256×320 투명 PNG. 숫자 높이 약 220px, 하단 기준 y=296. 점수/체력/타이머에 사용 가능합니다.
- health/hp_frame.png: 1024×204, 내부와 외부가 투명한 테두리.
- health/hp_fill_red.png 및 hp_fill_blue.png: 각 864×104 채움 텍스처.
- preview.png: 조합 예시, 실제 게임 리소스와 달리 불투명 배경입니다.

## 체력바 조합

테두리를 (0,0)에 1024×204로 그린다고 할 때 채움 영역은 (64,48,896,112)입니다. 먼저 해당 영역에 어두운 배경을 그리고 채움 텍스처를 해당 영역에 맞춰 표시한 뒤, 테두리를 맨 위에 겹칩니다.

체력비율 r=clamp(현재체력/최대체력,0,1). 채움 텍스처의 원본 너비와 표시 너비를 모두 r배로 잘라 표시합니다. 전체 텍스처를 좁게 압축하면 무늬가 찌그러지므로 잘라서 표시하세요. 오른쪽에서 줄어드는 바는 왼쪽에 고정, 반대편 바는 오른쪽에 고정합니다.

실제 게임에서 축소 크기와 숫자 간격을 맞춰 주세요.
