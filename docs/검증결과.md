# 검증 결과

## 정상 확인

- glc2d 시험 버전: 사용자가 화면 및 이동·점프·공격 조작 정상 확인.
- glc2d 렌더링 자동 검사: 17개 장면, PNG 436개 로드, G2Texture.Draw 1,039회, G2Font.DrawText 548회, G2Audio 음악 재생 확인. 음성 보이스 해제 수정 후 정상 종료.
- 원본 반영 후 Release 빌드 및 NuGet 복원 성공 (2026-11-09).
- 원본 실행 파일의 자동 검사: 총 61개, 실패 0개.
- 리소스: 목록과 실제 파일 437개가 일치. PNG 436개 + MP3 1개.

## 원본 경로에서 남은 실행 환경 확인

원본 경로의 렌더링 검사에서는 Windows 애플리케이션 제어가 Vortice.WinForms.dll을 차단했습니다 (FileLoadException, 0x800711C7). Windows CodeIntegrity 이벤트 3077에서 확인했습니다. 해당 DLL의 SHA-256은 정상 시험 버전과 동일합니다. 따라서 원본 경로에서의 렌더링 검사는 통과로 기록하지 않습니다. 사용자가 Visual Studio Release F5에서도 동일한 차단 오류가 발생한다고 확인했습니다 (2026-11-09).

보안 정책 변경 없이 소스와 제출 리소스 정리를 마쳤습니다. 제출 환경에서도 .NET 9 SDK 및 기존 NuGet 패키지 복원과 실행 허용 여부를 확인해야 합니다.

동봉한 self-test-results.txt는 원본 반영 후 결과이고, glc2d-smoke.json은 앞서 정상 완료한 시험 버전 결과입니다.

## 차단 원인 추가 확인 (2026-11-09)

- 스마트 앱 컨트롤 정책 값 VerifiedAndReputablePolicyState = 1 (켜짐).
- Vortice.WinForms.dll Authenticode 서명 검사: NotSigned.
- DLL 파일은 정상 시험 버전과 해시가 같지만, 원본 경로에서는 자동 실행과 F5 모두 차단됩니다. 앞선 시험 버전의 성공이 현재 원본 실행 성공을 보장하지 않습니다.
- 보안 정책을 유지하려면 신뢰할 수 있는 인증기관의 코드 서명 또는 수업에서 허용하는 개발 환경이 필요합니다. 현재 확인된 NuGet 최신 버전도 3.8.3으로, 단순 최신 버전 업데이트로 해결된다고 안내하지 않습니다.
- Windows 보안 설정은 변경하지 않았습니다. 현재 ZIP은 소스 수정본이며, 이 PC에서 실행 완료된 최종본으로 취급하지 않습니다.
